## P6 step 3b-3 — the last four artifact-egress keys (`d89ab79`, docs `e49b7c7`)

Found the step **already implemented but uncommitted** (6 modified files). Verified it, fixed two type
errors, committed. **140 of 144 keys now route**; `registerIpcHandlers()` is blocked on four keys, not
eight.

The primitive it needed was `File_Ops_Protocol.md` §3.2's ordering rule: *the dialog runs before the
command*. `writeArtifact` bundled "ask where" with "write", forcing the dialog after the render — fine
for the five egress methods whose artifact already exists, wrong for the two that make the engine render
something the user might abandon. Split into `pickSavePath(opts)` (ask, return a path, write nothing)
and `writeArtifact(…, destPath?)`; ingress needed the mirror, `readArtifactFile(opts?)` taking a path
and returning one.

Three client-side defects fell out — all reachable only once the preload stopped overriding the method:

- `exportRunnerReport` hardcoded `format: "json"` while the dialog offers HTML or JSON and derives the
  format from the chosen extension. Routing it as it stood would have silently deleted HTML export.
- `importData` ignored `req.filePath` and re-opened a picker. Now reuses the path **and** the staged
  blob (`pendingUploads`), so the bytes cross once.
- `readArtifactFile` was a pass-through to `dialog:openFile`, capped at **1 MB**; the legacy channel
  accepted `BLOB_MAX_INGRESS_BYTES` (100 MB), so it would have rejected every import between 1 MB and
  100 MB.
- Plus `exportData` read `req.workspaceId` where `ExportRequest` has `wsId` — every export would have
  been a `BAD_REQUEST`. Same shape as finding 5: the surface test cannot see a wrong payload.

## Two gaps that are decisions, not tasks

1. **`BIFURC_ENGINE_RPC=0` does not exist anywhere.** The rollback flag is a P6 *gate* item. It is no
   longer expressible as the plan wrote it: the plan assumed the preload's old channel table would
   survive as the fallback branch, and 3b-1 deleted it. Either re-add that table as dead-by-default
   code, or accept `git revert` as the only rollback layer.
2. **The "connecting to engine" UI state is renderer work**, which non-negotiable #1 forbids in P1–P6.
   The plan lists it as P6 work item 3, so the plan contradicts its own non-negotiable.
