# Handler classification

**The deliverable of P1 work item 1.** Every `ipcMain.handle` channel assigned to exactly one class.

- **ENGINE** — pure engine logic, becomes an RPC command
- **CLIENT** — only meaningful on the user's machine (dialogs, tray, zoom, trust store), never crosses the wire
- **SPLIT** — both halves exist and must be coordinated
- **DROP** — dead code, delete

Method:

```bash
grep -rn "ipcMain.handle" src --include=*.ts
```

Expected: **112** calls. Plus the CRUD handlers generated by
`src/ipc/handlers/entityCrudFactory.ts` (`registerEntityCrudHandlers`), which do not appear in the grep.

The pre-populated table in `02-phase-1-protocol.md` is a **hypothesis** — verify every row against source
before trusting it.
